Matematik STX B-niveau | Parallelforskydning af grafer: g(x) = f(x - k) + h

Teori: g(x) = f(x - k) + h

Standardformlen for parallelforskydning af en graf er:

g(x) = f(x - k) + h
Vandret forskydning (k):

Bemærk minusset inde i parentesen (x - k):

  • Hvis k = 3 → f(x - 3): Grafen flyttes 3 enheder til HØJRE.
  • Hvis k = -3 → f(x - (-3)) = f(x + 3): Grafen flyttes 3 enheder til VENSTRE.
Lodret forskydning (h):

Tallet uden for parentesen flytter grafen op eller ned:

  • Hvis h > 0 (fx +2): Grafen flyttes OP.
  • Hvis h < 0 (fx -2): Grafen flyttes NED.

Eksempel med f(x) = x²:

Funktionen g(x) = (x - 2)² + 3 har k = 2 og h = 3.

Toppunktet flyttes fra (0,0) til (2, 3) — altså 2 til højre og 3 op.
